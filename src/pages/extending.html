Extending the kit

Most extension points are an enum case. The exhaustive match arms tell you what's still missing.

A new screen

  1. Create resources/views/pages/{group}/⚡name.blade.php, a single-file Livewire component.
  2. Route it with Route::livewire('/path', 'pages::group.name') in the right workspace's route file.
  3. Call setPageGate() if it belongs to the admin workspace, and grant the gate to any custom role that needs it.
  4. If it changes an account, add the impersonation abort_if to mount().
  5. Log every admin write, confirm every destructive action, and write the test.

A third workspace

  1. app/Http/Middleware/{Type}Middleware.php: a copy of UserMiddleware with the new enum case.
  2. routes/{type}.php.
  3. A route group in bootstrap/app.php.
  4. A case in UserTypeEnum, then the match in UserService::middlewareGeneralCheck() and the branch in WithAuthWorker::userDashboardRedirect(). Both are exhaustive, so PHP tells you if you've missed one.
