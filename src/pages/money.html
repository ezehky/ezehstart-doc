Ledger and currencies

A transaction ledger that can't disagree with itself, shown in each viewer's own currency.

The ledger

transactions is the core table. Next to it sit gateway, meta, evidence, balance and charge rows.

  • Balances are derived from confirmed rows under a row lock, never stored as a free-standing number, so a balance can't silently disagree with the ledger that explains it.
  • Money is integer minor units throughout (see MoneyCast).
  • Administrators get a review queue and a manual adjustment that records who moved what, and why.
  • Members see their own statement at /app/transactions.

Currencies

currencies holds rates against one default currency. The ledger is stored in the default currency only, and every other currency is just a way of reading it. users.currency_id set to null means "use the default". Changing someone's currency never touches a stored row. 

{!! kMoneyFormat($amount) !!}                    // converted for the viewer
{!! kMoneyFormat($limit, convert: false) !!}     // a limit or an input: don't convert
kMoneyFormat($amount, decodeHtml: true)          // anywhere HTML isn't rendered

kMoneyFormat() returns an HTML entity, so Blade needs {!! !!} to print it.

<x-form.money-field> gives Livewire a plain number, whatever the display looks like.
