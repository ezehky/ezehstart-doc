Testing

Pest 5. Every change comes with a test.

Running

php artisan test --compact
php artisan test --compact --filter=Impersonation

The suite is large (over 700 tests at the last release) and runs on SQLite. Walk .agents/my-skills/checklist.md before calling anything done.

Things that will catch you out

  • The site configuration is a file, not a table, so RefreshDatabase doesn't reset it. tests/Pest.php fakes the disk for every feature test.
  • EmailRule does a live DNS MX lookup. It's off under test. To exercise it, pass new EmailRule(required: true, max: 190, verifyMailServer: true).
  • Emailed codes have a 60-second resend floor. A test that calls resend twice gets a validation error rather than a second email. Advance time or clear the cache between the two calls.
  • Anonymized accounts are soft-deleted, so User::find() won't find them. Use AccountDeletionService::trashedQuery().

Where tests go

Read .agents/my-skills/testing.md for layout, naming and the factories. The testing-best-practices skill covers choosing coverage and assertions.
