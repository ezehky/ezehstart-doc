Blog

Posts, categories and tags, with a public index and post pages.

Writing

  • A tiptap editor that inserts images and videos directly from the libraries. It loads lazily, so it only costs anything on pages that use it.
  • Posts can be scheduled, featured and archived. blog:publish-scheduled runs every minute, publishes each post at its time, and notifies subscribers.
  • The public post page shows related reading, plus an author card for posts written by an Author.

Categories and tags

Categories are polymorphic: one categories table serves every kind of category, separated by CategoryGroupEnum. When your project adds products, they can reuse the same table and admin screen instead of getting a second one. Tags work the same way.

Authors

The seeded Author role limits an account to the posts it wrote, and gives it a public byline with the bio and social handles from user_profiles, rendered by <x-site.author-card>.

Safety

Post HTML is sanitised on the way in by BlogService::sanitize(). That's what makes {!! $post->content !!} safe on the public page, so don't bypass it.

sanitize() rebuilds every <iframe> instead of cleaning it, because strip_tags keeps the attributes on any tag it allows. The src is resolved again through VideoProviderEnum, and the tag is written fresh from the provider and id. An iframe pointing anywhere else is dropped. To allow a new host, add a case to that enum and nowhere else.

Rich-text content is styled by .rich-prose in app.css, not by prose. @tailwindcss/typography isn't a dependency, so prose classes compile to nothing.
