Installation

From clone to a signed-in admin in a few minutes.

Requirements

  • PHP 8.3 or newer, with the extensions Laravel 13 needs
  • Composer 2
  • Node.js and npm, for the Vite build
  • A database. The example environment uses SQLite, so nothing needs to be running to get started
  • Optional: jpegoptim, optipng and pngquant for image optimisation. Uploads still work without them, just unoptimised

Set up

composer setup

That single script runs, in order:

  1. composer install
  2. copies .env.example to .env if there isn't one yet
  3. php artisan key:generate
  4. php artisan migrate --force
  5. php artisan storage:link
  6. npm install and npm run build

Seed the essentials

php artisan db:seed

This creates the roles (including the protected admin role and the Author role), the notification types, all 250 countries (read from database/data/countries.json, with no network call), the site configuration, and one administrator:

Emailadmin@example.test
Passwordpassword

Change these before the kit becomes a real project. They're set in database/seeders/UserSeeder.php.

Run it

composer dev

This starts three processes together: php artisan serve, a queue worker (queue:listen), and the Vite dev server. Sign in at /login. An admin lands on /app-splash and a member on /app.

Demo data (optional)

For a dashboard with something in it (invented people, a ledger, posts, FAQs and v1.0 of the three legal pages):

php artisan db:seed --class=DemoSeeder

It's deliberately kept out of DatabaseSeeder: a real install shouldn't start with invented money or placeholder legal copy. Every seeder under it matches on a natural key, so running it again refreshes the data rather than doubling it.

The demo policies only show the shape of a policy. They're not legal advice. See the disclaimer.
