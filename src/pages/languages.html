Languages

Interface translation using Laravel's JSON language files, with a machine-translation helper for development.

How it works

LocaleEnum lists the languages the kit knows how to describe: English, French, Spanish, Portuguese, German and Arabic. A language is only offered to visitors once its lang/{code}.json file exists. English and French ship today.

Guest screens are fully wrapped in __(). Dashboard screens are wrapped as they're worked on.

Adding a language

php artisan lang:extract      # collect every __() string into lang/en.json
php artisan lang:translate fr # machine-translate into lang/fr.json

Review the output by hand. lang:translate uses stichoza/google-translate-php, a development-only dependency. Never call it at runtime.

Translate this page

A second, separate tool: <livewire:livewire.page-translator> in the public header puts Google's website translator behind the site's own menu. It machine-translates whatever is on screen in the visitor's browser, posts and pages included, which no lang/{code}.json file can reach. It never changes the server's locale, and the language switcher above carries on serving the reviewed files.

  • Off by default (translator.status). Turn it on under Configuration › Preferences › Translate this page.
  • The same card picks the languages offered, by name. French, Spanish, Portuguese, German and Arabic are there to start. Names and flags come from database/data/translator-languages.json (61 languages), so nobody has to know that Yorùbá is yo. PageTranslatorService reads it, and a code no longer in the file is dropped from the menu.
  • Google's script loads only once a visitor picks a language. The choice is kept in Google's googtrans cookie, so it follows the visitor from page to page.
  • Google's own banner, tooltip and highlight are hidden in app.css. The site's menu replaces them.

If you turn it on, say so in your policies. The menu loads a script from translate.google.com and sets the googtrans cookie. Mention both in your cookie and privacy policies.
