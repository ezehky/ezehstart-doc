Languages

Interface translation using Laravel's JSON language files, with a machine-translation helper for development.

How it works

LocaleEnum lists the languages the kit knows how to describe: English, French, Spanish, Portuguese, German and Arabic. A language is only offered to visitors once its lang/{code}.json file exists. English and French ship today.

Guest screens are fully wrapped in __(). Dashboard screens are wrapped as they're worked on.

Adding a language

php artisan lang:extract      # collect every __() string into lang/en.json
php artisan lang:translate fr # machine-translate into lang/fr.json

Review the output by hand. lang:translate uses stichoza/google-translate-php, a development-only dependency. Never call it at runtime.
