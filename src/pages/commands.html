Commands

Every command you're likely to run while working on the kit.

Composer scripts

composer setup     # install, key, migrate, storage link, npm install, build
composer dev       # server + queue + vite together
composer test      # Pint, PHPStan and the suite, as CI runs them

Quality

php artisan test --compact                 # the whole suite
php artisan test --compact --filter=X      # one file or one test
vendor/bin/pint --dirty                    # after touching any PHP
vendor/bin/phpstan analyse --memory-limit=1G

Kit commands

CommandPurpose
account:send-deletion-remindersFive-day and one-day deletion warnings
account:process-deletionsAnonymize or remove accounts whose window has ended
blog:publish-scheduledPublish due posts and notify subscribers
email:send-campaignsSend due campaigns in chunks
activity:prune-logsApply the activity-log retention window
lang:extractCollect translatable strings into lang/en.json
lang:translate {code}Machine-translate into another language (development only)

The scheduled commands all accept --dry-run.

Seeding

php artisan db:seed                      # roles, countries, notification types, config, one admin
php artisan db:seed --class=DemoSeeder   # invented people, ledger, posts, FAQs, policies
